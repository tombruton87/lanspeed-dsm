A computer: iperf3

iperf3 measures the network alone, with no browser in the way — the most exact test. This Synology's iperf3 server listens on 5201 (TCP and UDP) . Install iperf3 on the computer, then run these there; each result shows up in History.

The other way round — this Synology testing the computer — is Run a test: start iperf3 -s on the computer first.

What limits the result

  • Wi-Fi is shared and half-duplex: expect roughly half the link speed the device shows, less through walls or far from the access point. Test wired first to know what the Synology itself manages.
  • 1 GbE ports top out at about 940 Mbit/s with TCP. The slowest link on the way counts: the Synology's port, the switch, the cable, the device's port.
  • Several ports on the Synology (link aggregation) don't make one test faster — a single connection uses one port. Parallel streams can spread over them.
  • The browser test also depends on the device and browser; a small phone or an old laptop can be the limit. Through DSM's reverse proxy or a VPN, those are measured too.
  • File copies are not involved: iperf3 and the browser test send data from memory, so disks, SMB and the Synology's shares don't count. If copies are much slower than these results, look at the disks or SMB settings, not the network.
  • Small Synology models may run out of processor before a 2.5 or 10 GbE link is full; several parallel streams help a little.
